# The Research Library

A curated, categorised library of the open-source projects I study — maintained by [Ayush Shukla](https://github.com/Ayushshuklai).

This is the working library behind my own projects. It is organised the same way as my [GitHub Starred Lists](https://github.com/Ayushshuklai?tab=stars): every project sits in exactly one primary category, with the description its authors wrote for it. Several projects in the Finance & Trading section directly inspired my own multi-agent stock-research system, [Arthon](https://github.com/Ayushshuklai/arthon).

**How to use it:** browse by category below, or use GitHub's own list view from my profile's Stars tab. Star counts are deliberately not shown — they go stale; the links are the canonical source. Each project's licence is its own; check before reuse.

*Main catalog: 140 projects, extracted 2026-10-31; 5 trading repos added 2026-11-17. A further curated set — Lead Generation Tools (30 starred + 1 archived) — lives in its own list, linked in the final section.*
